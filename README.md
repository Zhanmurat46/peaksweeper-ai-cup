# 🏔️ PEAKSWEEPER: Avalanche Protocol

Веб-игра, разработанная соло в рамках **nFactorial AI Cup 2026** с использованием методологии **Vibe Coding** через *Claude Code* в *Antigravity IDE*.

### 🎯 Концепт и Переосмысление Классики
Игра переосмысляет классический "Сапёр" (Minesweeper), превращая его в вертикальный Roguelike-симулятор восхождения на горную вершину. Вместо хаотичного клика по всему полю, игрок совершает тактическое пошаговое восхождение.

### 🕹️ Твисты Механики:
* **Вертикальный геймплей:** Движение снизу вверх, каждый уровень сетки — новые сотни метров высоты.
* **Элементы Рогалика:** Сбор очков снабжения (монет) за безопасные шаги.
* **Магазин перков:** Покупка кислородных баллонов (сохраняют жизнь при взрыве) и ледорубов между раундами.

### 🛠️ Технический Стек:
* React (Vite)
* Tailwind CSS v4
* Claude 3.7 Sonnet (Claude Code Agent)
