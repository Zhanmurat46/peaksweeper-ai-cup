## 🎯 Описание концепта
**PeakSweeper** — это хардкорное переосмысление классического "Сапёра" (Minesweeper) в сеттинге вертикального роглайк-восхождения. Вместо хаотичного раскрытия клеток на плоскости, игрок в роли альпиниста штурмует величайшие вершины мира, просчитывая лавинные риски на каждом шаге снизу вверх.

## 🕹️ Геймплей и Фичи (User Flow & Juicy UI)
* **Атмосфера и Иммерсивность:** Динамический эффект снежного бурана, уникальные кинематографичные фоны для каждой вершины (Белуха, Хан-Тенгри, Эверест).
* **Аудио-движок (Web Audio API):** Полностью процедурный звук завывания ветра, металлический клик ледоруба и сочный грохот лавины без использования тяжелых внешних медиа-файлов.
* **Идеальный User Flow:** Мгновенный бесшовный перезапуск раунда кнопкой "Реванш" или клавишей `R`. Встроенный магазин снаряжения прямо в экран окончания экспедиции.
* **Мета-прогрессия:** Регистрация позывного альпиниста, система рекордов высоты и спидран-таймеров, сохраняющаяся в `localStorage`.
* **Элемент обморожения:** Динамический CSS-эффект замерзания экрана, если игрок думает над тактическим ходом дольше 15 секунд.

## 🛠️ Технический Стек
* **Frontend:** React (Vite), Tailwind CSS
* **Архитектура:** Модульный State-менеджмент (Кастомные хуки для управления логикой генерации мин и состоянием инвентаря)
* **Методология:** Vibe Coding (Разработка в синергии с ИИ-агентами Claude Code)
